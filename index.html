Upload Theme Files

Upload files from the pterodactyl folder to your Pterodactyl panel folder via SFTP.

Default location:

/var/www/pterodactyl

Important Note

If you're updating the theme, skip to step 3 to save time!

2

Install Yarn

Run the following commands in your terminal to install Yarn:

Ubuntu/Debian

# Install dependencies
sudo apt install -y ca-certificates curl git gnupg unzip wget zip

# Add Node.js apt repository
sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://deb.nodesource.com/gpgkey/nodesource-repo.gpg.key | sudo gpg --dearmor -o /etc/apt/keyrings/nodesource.gpg
echo "deb [signed-by=/etc/apt/keyrings/nodesource.gpg] https://deb.nodesource.com/node_22.x nodistro main" | tee /etc/apt/sources.list.d/nodesource.list
sudo apt update
sudo apt install -y nodejs

# cd into Pterodactyl, install yarn and node dependencies
cd $PTERODACTYL_DIRECTORY
npm i -g yarn
yarn install

npm i -g yarn

CentOS

curl -sL https://rpm.nodesource.com/setup_16.x | sudo -E bash - &&
sudo yum install -y nodejs yarn

Then install Yarn on your Pterodactyl panel:

cd /var/www/pterodactyl && yarn

Pro Tip

Make sure you have sudo privileges before running these commands. If you encounter issues, try prefixing commands with sudo.

3

Run Theme Watcher

Since the new theme version you need to install react-icons:

yarn add react-icons

also install browsertigy:

yarn add path-browserify

Navigate to your Pterodactyl directory and run the watcher command:

cd /var/www/pterodactyl && yarn watch

If yarn watch command fails with the error 'ERR_OSSL_EVP_UNSUPPORTED' run this command:

export NODE_OPTIONS=--openssl-legacy-provider

After running that command run yarn watch command again

Important Note

If errors appear on yarn watch, don't panic, that's normal and you just proceed by hitting CTRL + C on your keyboard to exit yarn watch command and continue with the last step.

4

Post-Installation Commands NEW

After running the watcher, execute these commands to complete the installation:

Run database migrations:

php artisan migrate

Create storage link:

php artisan storage:link

Clear application caches:

php artisan view:clear
php artisan cache:clear
php artisan config:clear

Set proper permissions:

chown -R www-data:www-data /var/www/pterodactyl/*

Important

These commands are required for the new theme editor to function properly. Make sure to run them in order.

Troubleshooting

Common issues and their solutions:

Yarn Installation Failed

npm install --global yarn

Broken Dependencies

yarn install

Clear and Retry

rm -rf node_modules && yarn

Broken Elements

php artisan config:clear && php artisan cache:clear && php artisan view:clear && php artisan optimize:clear && php artisan optimize
